# AgentLab

**让 Agent 任务从工作台调试走向 API 集成。**

AgentLab 是面向开发者与团队的托管 Agent 执行与 Tools API 平台。选择模型与预设 Agent，上传文件或描述任务，在隔离沙箱中执行，获取可下载产物，并查看运行过程与费用。

## 核心能力

- **开箱即用的 Agent**：9 个预设，覆盖文件分析、数据处理、代码生成、专属工作台搭建等场景，支持多轮对话与文件上传。
- **可交付的执行结果**：在 Docker 沙箱中执行代码，生成表格、图表或源码 ZIP；支持平台模型与自带模型账户（BYOK）。
- **统一的 API 集成**：工作台与外部应用调用同一 Agent 版本；3 个内置工具也可通过 Tools API 独立调用。
- **过程与成本可查**：查看运行事件、工具调用和产物，通过项目预算、任务费用上限及分项用量控制成本。

技术栈：React + TypeScript · Go · MongoDB · Docker。

## 路线图

| 阶段          | 状态       | 交付重点                                                                            |
| ------------- | ---------- | ----------------------------------------------------------------------------------- |
| P0 执行闭环   | 本地已完成 | 工作台与 API、模型接入、隔离执行、文件产物、预算与账本                              |
| P1 工作台完善 | 持续推进   | 已支持多轮对话与运行观测；后续补齐自定义 Agent 草稿与发布、审批、Webhook 和成员协作 |
| P2 云端试点   | 规划中     | 弹性执行、对象存储、受管凭据与商业支付                                              |
| P3 场景扩展   | 按需求推进 | 私网模型、浏览器工具、OAuth 与更多连接器                                            |

当前为已通过真实模型、MongoDB 与 Docker 主链路验证的本地 MVP；云端多租户与 SLA 仍待验证，详细范围见[实施现状](docs/implementation-status.md)。
