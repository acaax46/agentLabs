## 数据和导出范围

业务记录只来自接口。浏览器仅按登录用户保存运行列表的筛选条件、视图名称和列偏好，不保存 Run、用量、账本、文件或秘密。命令面板按完整 ID 请求接口，由服务端校验归属；它不是全文搜索服务。

用量明细与只追加账本的标签选择写入 URL，刷新后恢复原视图；切换视图清除分页游标，避免沿用另一类明细的游标。

CSV 只导出当前已加载页，金额包含币种，字符串防止表格公式注入。跨项目汇总最多选择当前已加载且有权访问的五个项目，分别请求服务端汇总；CNY/USD 不相加、不换算，不把预算当作充值余额。

Excel 仅支持未加密 `.xlsx` 首表，文件最多 8 MB、每个读取的 XML 解压最多 2 MB、压缩目录最多 400 项、预览最多 50 行和 20 列。公式不执行，只显示缓存值；外部实体和外部表引用被拒绝。旧 `.xls`、加密或不支持的工作簿保留授权下载入口。图表只使用预览中最多 50 行数值，不代表全文件统计。

批量下载限当前页选择的 10 个可用文件、20 MB；每个文件都重新申请短时下载授权，出错不生成不完整的 ZIP。ZIP 附原文件摘要清单。证据包重新读取运行、调用、产物、用量、账本和事件；各类分页明细最多 100 条、事件最多 1000 条，保留后续游标和 `partial` 标记，原文件另行下载。快照读取期间可能有状态变化，不宣称事务一致或完整归档。

## 验证命令

在根目录使用 `pnpm --filter @agentlab/frontend check`、`lint`、`build` 和 `test:e2e:p1`。P1 浏览器测试使用受控接口，覆盖 1440px、1024px、390px 与 200% 等效视口；输出 `.cache/p1-ui-results`，不等同于真实后端验收。真实工具验收使用独立数据库与现有生产构建，结果和边界另行记录。

`test:e2e:p1:regression` 将既有界面回归写入独立的 `.cache/p1-regression-results`，保留早期 P0 证据。`test:e2e:p1:acceptance` 在 `dev:acceptance` 的独立后端上运行真实文件工具验收，使用生产前端构建、关闭网络 trace，不调用模型推理。须先完成构建，并满足前端 README 的真实验收环境前提；它仍会创建独立项目、上传文件并产生真实工具用量记录。

## 本机验证结果（2026-10-25）

- lint 零错误、17 项警告；TypeScript、相关 Prettier、`git diff --check` 和生产构建通过。构建仍有大于 500 kB 的包体积提示。
- P1 共 48 个视口场景，整轮 46 项通过、2 项在浏览器启动/退出时超时；工具调用与证据包随后逐项重跑 8/8 通过。账本视图修正后，四视口的用量/账本恢复与 CSV 用例 4/4 通过。重跑分别保留在 `.cache/p1-recheck-results` 和 `.cache/p1-ledger-results`。
- 原有工作台整轮 84 项中 82 项通过、2 项超时；复核另外发现账本标签恢复问题，改为 URL 驱动后，相关账单、空状态及键盘标签页用例 6/6 通过，保存在 `.cache/p1-regression-final-results`。没有将首次整轮记录改写成全绿结果。
- 独立数据库上的真实文件工具调用，桌面 1440px 与手机 390px 两项通过，包含上传、固定版本提交、成功、已结算、调用历史和授权 ZIP 下载。当前种子价格下费用为 `0` CNY；这验证状态和计量链路，不证明正价扣费或商业支付。未调用模型推理。
- 四份受控下载 ZIP 与两份真实下载 ZIP 的 CRC、目录及清单检查通过；真实 `merged.csv` 包含预期数据，内容 SHA-256 与产物清单一致。已人工查看桌面、平板、手机截图。`200%` 项为等效视口，不将其声明为本轮原生浏览器缩放验收。
- 本轮临时验收 API 已停止，数据库与本地产物保留作为证据；后端源码未修改。发布、审批、Webhook 等上表缺口继续保留“未开放”。
