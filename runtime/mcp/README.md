# 工具与 MCP 候选目录

新平台的工具边界与计费见 [平台总设计](../../docs/agentlab-platform-design.md)。MCP 是工具接入方式之一，不能把协议可连接等同于工具可商业托管。

当前 catalog.json 是旧原型的候选清单，包含题目查询等实验项目；它不是新版 Tools API 的可用能力或收费目录。本轮不更新清单或启动 worker，不继续以课堂/比赛工具作为主产品路线。

后续每个工具版本需要明确输入/输出 schema、授权目标、风险、结果大小、超时、资源限制、计量单位、价格、幂等与未知结果处理。外部写操作按冻结参数和资源范围审批，未知工具和任意 URL 代理默认不开放。

真实 Cookie、API Key、OAuth token 留在执行域外。工具说明、返回内容、resources 和 prompts 都可能是不可信输入，不能绕过平台策略或变更权限。

已有 validate_catalog.py 用于检查候选清单中的风险字段，不证明真实供应商兼容、安全认证或平台收费已可用。题目提交等旧实验副作用的原请求仍需核对，不能因产品改名就自动重发。
