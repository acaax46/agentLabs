# AgentLab 持久化边界

数据库使用 MongoDB，禁止新增 SQLite 持久化。mongo.go 连接宿主配置的副本集，本地/CI 使用根目录 compose.test.yaml。

现有集合承载本地身份、旧资料、连接、队列、工作区、预算与运行记录。新平台集合和租户/项目索引见 [平台总设计](../../../docs/agentlab-platform-design.md)；本轮不自动改名、迁移或删除数据。

状态、预占、账本、审计与 outbox 按业务事务组织；幂等、版本和租约使用唯一/复合索引。金额为整数微单位，传输用字符串；未知量为 null，只追加记录不能通过通用 CRUD 改写。

模型账户密文目前由 internal/connection 管理，宿主根密钥不入业务库；通用配置只引用连接，不能提供秘密导出。未来文件正文进入受限对象存储，MongoDB 保留归属、摘要与元信息，云端凭据使用独立受管服务。
